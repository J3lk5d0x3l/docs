Vyrron te permite crear un formulario de solicitud de staff personalizado para tu servidor. Los miembros pueden enviar aplicaciones estructuradas a traves de un panel interactivo, y el staff recibe las respuestas en un canal privado para evaluarlas.

## Comandos principales

| Comando | Descripcion |
| --- | --- |
| `/staffapp config channel` | Define el canal donde se enviaran las solicitudes recibidas |
| `/staffapp config questions` | Establece las preguntas del formulario separadas por `\|` |
| `/staffapp config manager-role` | Define el rol que recibira notificaciones de nuevas solicitudes |
| `/staffapp config color` | Personaliza el color del embed del panel |
| `/staffapp panel` | Publica el panel de solicitud de staff en el canal deseado |

## Proceso recomendado

1. Crea un canal privado exclusivo para el staff donde llegaran las solicitudes.
2. Define las preguntas del formulario usando `/staffapp config questions`. Separa cada pregunta con el caracter `|`.
3. Asigna un rol de manager de staff que recibira menciones cuando llegue una nueva solicitud.
4. Personaliza el color del embed para que coincida con la estetica de tu servidor.
5. Publica el panel con `/staffapp panel` en un canal visible para los miembros interesados.

Ejemplo de configuracion de preguntas:

```text
/staffapp config questions:Cual es tu edad?|Por que quieres ser staff?|Experiencia previa?|Horario de disponibilidad?
```

<Note>
  El rol de manager de staff debe tener acceso al canal privado de solicitudes. Vyrron mencionara ese rol automaticamente cada vez que un miembro envie una nueva aplicacion. Asegurate de que el canal este correctamente protegido para evitar filtraciones de informacion de los candidatos.
</Note>
