Vyrron te permite enviar mensajes de bienvenida cuando alguien se une al servidor y mensajes de despedida cuando alguien se va. Puedes personalizar el canal, el contenido y usar variables dinamicas para mencionar al miembro, mostrar el nombre del servidor y mas.

## Comandos de bienvenida

| Comando | Descripcion |
| --- | --- |
| `/greet setup` | Configura el canal y el mensaje de bienvenida |
| `/greet test` | Envía un mensaje de prueba para verificar la configuracion |
| `/greet reset` | Restablece la configuracion de bienvenida |
| `/greet variables` | Muestra la lista de variables disponibles |

## Comandos de despedida

| Comando | Descripcion |
| --- | --- |
| `/farewell setup` | Configura el canal y el mensaje de despedida |
| `/farewell test` | Envía un mensaje de prueba para verificar la configuracion |
| `/farewell reset` | Restablece la configuracion de despedida |
| `/farewell variables` | Muestra la lista de variables disponibles |

## Flujo de configuracion

1. Elige un canal dedicado para bienvenidas y otro para despedidas (pueden ser el mismo).
2. Ejecuta `/greet setup` o `/farewell setup` y selecciona el canal.
3. Escribe el mensaje usando variables como `$member_mention` y `$server_name`.
4. Usa `/greet test` o `/farewell test` para previsualizar el resultado.
5. Ajusta el mensaje hasta que se vea correcto.

## Variables de mensaje

| Variable | Descripcion |
| --- | --- |
| `$member_mention` | Mencion del miembro |
| `$member_name` | Nombre del miembro |
| `$member_id` | ID del miembro |
| `$member_count` | Cantidad total de miembros en el servidor |
| `$server_name` | Nombre del servidor |
| `$server_id` | ID del servidor |
| `$join_time` | Hora en que el miembro se unio |
| `$leave_time` | Hora en que el miembro se fue |
| `$creation_time` | Fecha de creacion de la cuenta del miembro |

<Note>
  `$leave_time` solo esta disponible en mensajes de despedida. `$join_time` muestra la fecha de union al servidor en bienvenidas y tambien puede usarse en despedidas.
</Note>

<Tip>
  Mantén los mensajes cortos y orientados a acciones. Incluye un enlace a las reglas o a un canal de presentacion para que los nuevos miembros sepan que hacer a continuacion.
</Tip>
