El sistema de niveles de Vyrron rastrea la participacion de los miembros mediante XP ganado por mensajes y tiempo de voz. Puedes mostrar tarjetas de rango personalizadas y recompensar a los miembros con roles automaticos al alcanzar niveles especificos.

## Comandos principales

| Comando | Descripcion |
| --- | --- |
| `/leveling enable` | Activa el sistema de niveles en el servidor |
| `/leveling disable` | Desactiva el sistema de niveles |
| `/leveling config` | Configura roles por nivel, canales ignorados y mas |
| `/leveling reset` | Reinicia todos los niveles y XP del servidor |
| `/rank` | Muestra tu tarjeta de rango |
| `/rank @usuario` | Muestra la tarjeta de rango de otro miembro |
| `/leaderboard levels` | Muestra la clasificacion de niveles del servidor |

<Note>
  Tambien puedes usar los aliases `,rank` y `,level` como comandos de mensaje.
</Note>

## Implementacion

<Steps>
  <Step title="Activa el sistema">
    Ejecuta `/leveling enable` para activar el rastreo de XP en tu servidor.
  </Step>
  <Step title="Configura roles por nivel">
    Usa `/leveling config` para asignar roles a niveles especificos. Los miembros reciben los roles automaticamente al subir de nivel.
  </Step>
  <Step title="Personaliza la experiencia">
    Define canales ignorados, multiplicadores de XP y otros ajustes desde `/leveling config`.
  </Step>
</Steps>

## Roles por nivel

Desde `/leveling config` puedes asignar roles de Discord a niveles especificos del sistema de Vyrron. Cuando un miembro alcanza ese nivel, Vyrron le asigna el rol automaticamente.

<Note>
  Vyrron necesita el permiso `Manage Roles` para asignar roles por nivel. Ademas, el rol de Vyrron debe estar posicionado por encima de los roles que asigna en la jerarquia del servidor.
</Note>

<Warning>
  `/leveling reset` es una accion destructiva. Elimina todos los datos de XP y niveles del servidor sin posibilidad de recuperacion. Usalo solo si estas seguro de querer reiniciar desde cero.
</Warning>
