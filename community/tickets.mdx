El sistema de tickets de Vyrron crea un flujo de soporte privado para preguntas, reportes y solicitudes. Los comandos de configuración y panel requieren **Gestionar servidor**; las acciones de ticket están disponibles para el autor del ticket o los roles de soporte configurados según corresponda.

## Configura el sistema

<Steps>
  <Step>
    **Crea el sistema.** Ejecuta `/ticket setup` y elige la categoría de tickets, el estilo del panel, el tipo de selector, el acceso del staff y el destino de los registros.
  </Step>
  <Step>
    **Añade categorías.** Usa `/category add` para flujos distintos como soporte, reportes o partnerships. Verifícalas con `/category list`. Un panel debe tener al menos una categoría.
  </Step>
  <Step>
    **Añade roles de soporte.** Usa `/supportrole add` para las personas que deben ver y gestionar tickets. Verifícalos con `/supportrole list`.
  </Step>
  <Step>
    **Publica el panel.** Ejecuta `/ticket panelsend` y selecciona un canal de texto o anuncios donde los miembros puedan abrir tickets. El panel puede usar botones o un menú de selección.
  </Step>
</Steps>

## Ciclo de vida del ticket

| Comando | Uso |
| --- | --- |
| `/ticket claim` | Reclamar un ticket abierto |
| `/ticket close` | Cerrar un ticket |
| `/ticket rename` | Renombrar el canal del ticket |
| `/ticket transfer` | Transferir la propiedad |
| `/ticket adduser` | Añadir un participante |
| `/ticket removeuser` | Eliminar un participante |
| `/ticket transcript` | Generar una transcripción |

`/ticket close` puede ser usado por el autor del ticket o el staff de soporte. `/ticket claim` y los comandos de gestión de acceso requieren un rol de soporte configurado o acceso de administrador. `/ticket rename` acepta un nombre de canal y lo normaliza a letras, números y guiones.

## Comandos de configuración

| Comando | Uso |
| --- | --- |
| `/ticket reset` | Reiniciar la configuración de tickets |
| `/category add` | Añadir una categoría de ticket |
| `/category remove` | Eliminar una categoría de ticket |
| `/category list` | Listar las categorías de tickets |
| `/supportrole add` | Añadir un rol de soporte |
| `/supportrole remove` | Eliminar un rol de soporte |
| `/supportrole list` | Listar los roles de soporte |

<Note>
  Mantén las transcripciones y los canales de tickets sujetos a la política de privacidad y retención de tu servidor. No expongas el contenido de soporte a roles que no lo necesiten. Cerrar un ticket cambia el estado del canal; reiniciar el sistema elimina su configuración y debe tratarse como una acción administrativa separada.
</Note>
