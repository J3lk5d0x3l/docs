El sistema de tickets de Vyrron te permite crear un flujo de soporte privado en tu servidor de Discord. Los miembros pueden abrir tickets mediante un panel interactivo, y el staff puede gestionarlos con comandos dedicados que incluyen reclamar, transcribir y cerrar conversaciones.

## Configura el sistema

<Steps>
  <Step title="Define la categoria">
    Ejecuta `/ticket config category` y selecciona la categoria de canales donde se crearan los tickets.
  </Step>
  <Step title="Asigna el rol de soporte">
    Ejecuta `/ticket config support-role` y menciona el rol que podra ver y gestionar los tickets.
  </Step>
  <Step title="Configura transcripciones (opcional)">
    Si deseas guardar transcripciones, configura el canal de registros con `/ticket config transcript-channel`.
  </Step>
  <Step title="Publica el panel">
    Ejecuta `/ticket panel` para enviar el mensaje embed con el boton de crear ticket al canal deseado.
  </Step>
</Steps>

## Ciclo de vida del ticket

| Etapa | Comando | Descripcion |
| --- | --- | --- |
| Crear | Boton del panel o `/ticket create` | El miembro abre un nuevo canal de ticket |
| Reclamar | `/ticket claim` | Un miembro del staff toma responsabilidad del ticket |
| Agregar | `/ticket add @usuario` | Invita a otro usuario al canal del ticket |
| Transcribir | `/ticket transcript` | Genera una transcripcion del ticket |
| Cerrar | `/ticket close` | Cierra el ticket y archiva el canal |
| Eliminar | `/ticket delete` | Elimina el canal del ticket inmediatamente |
| Reabrir | `/ticket reopen` | Reabre un ticket previamente cerrado |

## Comandos de configuracion

| Comando | Descripcion |
| --- | --- |
| `/ticket config category` | Establece la categoria donde se crean los tickets |
| `/ticket config support-role` | Define el rol que puede gestionar tickets |
| `/ticket config transcript-channel` | Canal donde se envian las transcripciones |
| `/ticket config max-tickets` | Limite de tickets abiertos por miembro |
| `/ticket config ticket-name` | Formato del nombre de los canales de ticket |
| `/ticket panel` | Publica el panel de creacion de tickets |
| `/ticket stats` | Muestra estadisticas del sistema de tickets |

<Note>
  Los canales de ticket son privados: solo el creador, el staff con rol de soporte y los usuarios agregados manualmente pueden verlos. Las transcripciones se guardan en el canal configurado y pueden conservarse incluso despues de eliminar el ticket.
</Note>
