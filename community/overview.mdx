Vyrron incluye múltiples sistemas de comunidad que puedes combinar para crear una experiencia de servidor completa. Cada sistema tiene su propio conjunto de comandos y permisos, y puedes activar solo los que necesites.

Los permisos requeridos varian segun la funcion:

- **Bienvenida y despedida**: `Manage Guild` (solo para configuracion)
- **Niveles**: `Manage Guild` (configuracion); cualquier miembro (ver su rango)
- **Tickets**: `Manage Guild` (configuracion); rol de soporte (gestionar tickets)
- **Sorteos**: `Manage Messages` (crear y gestionar sorteos)
- **Sugerencias y feedback**: `Manage Guild` (configuracion); cualquier miembro (enviar)
- **Voicemaster**: `Manage Guild` (configuracion)
- **Autopost y notificaciones sociales**: `Manage Guild` (configuracion)

## Incorporacion y participacion

| Sistema | Comando de inicio | Comando de seguimiento |
| --- | --- | --- |
| Bienvenida | `/greet setup` | `/greet test` |
| Despedida | `/farewell setup` | `/farewell test` |
| Niveles | `/leveling enable` | `/leveling config` |
| Tickets | `/ticket config` | `/ticket panel` |
| Sorteos | `/giveaway start` | `/giveaway list` |
| Sugerencias | `/suggestion config` | `/suggestion review` |
| Feedback | `/feedback config` | — |

<Note>
  Antes de una oleada de miembros, prueba siempre los mensajes de bienvenida y despedida con `/greet test` y `/farewell test` para verificar que el canal, las variables y el formato se ven correctos.
</Note>

## Soporte y operaciones de staff

### Tickets

El sistema de tickets de Vyrron crea un flujo de soporte privado con categorias, roles de soporte y transcripciones. Para configurarlo:

```text
/ticket config category:<ID de categoria>
/ticket config support-role:<@rol>
/ticket panel
```

| Etapa | Comando | Quien lo usa |
| --- | --- | --- |
| Crear | Boton del panel o `/ticket create` | Miembro |
| Reclamar | `/ticket claim` | Staff de soporte |
| Agregar | `/ticket add <@usuario>` | Staff de soporte |
| Transcribir | `/ticket transcript` | Staff de soporte |
| Cerrar | `/ticket close` | Staff de soporte o miembro |
| Eliminar | `/ticket delete` | Staff de soporte |
| Reabrir | `/ticket reopen` | Staff de soporte |

### Solicitudes de staff

Crea un formulario de solicitud de staff consistente para recibir aplicaciones estructuradas:

```text
/staffapp config channel:<#canal>
/staffapp config questions:Pregunta 1|Pregunta 2|Pregunta 3
/staffapp config manager-role:<@rol>
/staffapp panel
```

## Automatizacion

Configura respuestas y reacciones automaticas para mensajes predecibles y preguntas frecuentes.

| Tipo | Configuracion | Ejemplo de uso |
| --- | --- | --- |
| Auto-responder | `/autoresponder add trigger:<texto> response:<texto>` | Responder "reglas" con el enlace a las reglas |
| Auto-reaction | `,autoreact add <#canal> <emoji>` | Reaccionar automaticamente en canales de presentacion |

## Voz y actividad del servidor

### Voicemaster

Crea canales de voz privados temporales automaticamente. Los miembros se unen a un canal hub y Vyrron genera un canal privado que pueden gestionar.

### Autopost y notificaciones sociales

Mantén canales activos con publicaciones automaticas y notificaciones de redes sociales.

| Fuente | Comando | Detalle |
| --- | --- | --- |
| Imagenes (Male/Female/Anime/Banners) | `/autopost config` | Publica imagenes programadas |
| YouTube | `/social add youtube <ID de canal> <#canal>` | Notifica nuevos videos |
| Reddit | `/social add reddit <subreddit> <#canal>` | Notifica nuevas publicaciones |

## Niveles y seguimiento

Vyrron rastrea tres señales de participacion: invitaciones, mensajes y tiempo de voz. Usa estos datos para recompensar la participacion.

| Area | Comandos de miembro | Comandos de clasificacion |
| --- | --- | --- |
| Invitaciones | `,invites`, `,invites @usuario` | `,leaderboard invites` |
| Mensajes | `,messages`, `,messages @usuario` | `,leaderboard messages` |
| Voz | `,voicetime`, `,voicetime @usuario` | `,leaderboard voicetime` |

Para configurar roles por nivel, usa `/leveling config` y asigna roles a niveles especificos. Los miembros reciben los roles automaticamente al alcanzar cada nivel.
