Vyrron te permite crear sorteos interactivos en tu servidor de Discord con requisitos configurables, duracion personalizada y multiples ganadores. Tambien puedes editar sorteos activos, finalizarlos antes de tiempo y seleccionar nuevos ganadores si es necesario.

## Comandos principales

| Comando | Descripcion |
| --- | --- |
| `/giveaway start` | Inicia un nuevo sorteo con duracion, premio y requisitos |
| `/giveaway edit` | Modifica un sorteo activo (premio, duracion, ganadores) |
| `/giveaway end` | Finaliza un sorteo antes de su tiempo programado |
| `/giveaway reroll` | Selecciona nuevos ganadores para un sorteo ya finalizado |

## Lista de verificacion para sorteos responsables

- Define claramente el premio y la duracion antes de iniciar.
- Establece requisitos razonables (por ejemplo, rol especifico o tiempo minimo en el servidor).
- Anuncia el sorteo con anticipacion para maximizar la participacion.
- Verifica que Vyrron tenga permisos para enviar mensajes y agregar reacciones en el canal elegido.
- Documenta la razon si necesitas hacer reroll o finalizar antes de tiempo.

<Note>
  La diferencia entre los comandos es clara: `/giveaway edit` modifica un sorteo que aun esta activo; `/giveaway end` lo cierra inmediatamente y anuncia ganadores; `/giveaway reroll` elige nuevos ganadores de un sorteo ya cerrado, util si el ganador original no reclama el premio.
</Note>
