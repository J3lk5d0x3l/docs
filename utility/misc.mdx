Vyrron incluye una variedad de herramientas menores que facilitan la gestión diaria de servidores: perfiles personalizados, encuestas, temporizadores, recordatorios y más. Estas funciones están disponibles para todo tipo de comunidades, grandes o pequeñas.

## Perfiles y media

| Comando | Descripción |
| --- | --- |
| `/profile` | Muestra tu perfil personal en el servidor |
| `/profileedit` | Edita la información visible de tu perfil |
| `/steal` | Guarda un emoji o sticker en el servidor actual |
| `,quote` | Crea una imagen de cita a partir de un mensaje |
| `/caption` | Añade un pie de foto a una imagen |
| `/get pfp` | Obtiene la foto de perfil de un usuario |
| `/get banner` | Obtiene el banner de un usuario |
| `/get wallpaper` | Obtiene un fondo de pantalla aleatorio |
| `/imdb` | Busca información de películas y series en IMDb |
| `/embed` | Crea un mensaje embed personalizado |
| `/container` | Envía un mensaje con formato de contenedor |

## Temporizadores e interacción

| Comando | Descripción |
| --- | --- |
| `/poll create` | Crea una encuesta con opciones de voto |
| `/poll end` | Finaliza una encuesta activa y muestra resultados |
| `/timer start` | Inicia un temporizador con duración personalizada |
| `/timer pause` | Pausa el temporizador activo |
| `/timer resume` | Reanuda el temporizador pausado |
| `/timer end` | Detiene el temporizador antes de tiempo |
| `/reminder add` | Crea un recordatorio programado |
| `/reminder list` | Muestra tus recordatorios activos |
| `/reminder remove` | Elimina un recordatorio específico |
| `/timezone` | Configura tu zona horaria personal |

<Note>
  Los temporizadores de Vyrron funcionan por usuario. Si inicias un temporizador, solo tú puedes pausarlo, reanudarlo o detenerlo. Los recordatorios se envían por mensaje directo o en el canal configurado.
</Note>

## Otras herramientas

| Comando | Descripción |
| --- | --- |
| `/report` | Reporta un problema o sugerencia al equipo de Vyrron |
| `/lookup` | Busca información pública sobre un elemento |
| `/define` | Consulta la definición de una palabra |
| `/nptoggle` | Activa o desactiva el modo no molestar de notificaciones |
| `/fix` | Intenta corregir un mensaje con formato incorrecto |
| `/lens` | Analiza una imagen con herramientas de visión |
| `/math` | Resuelve operaciones matemáticas complejas |
| `/todo` | Gestiona una lista de tareas personales |

<Note>
  El comando `,help cmdname` muestra ayuda rápida sobre cualquier comando sin necesidad de usar `/help`. Usa `/report` para enviar problemas directamente al equipo de soporte de Vyrron.
</Note>
