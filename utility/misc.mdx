Esta es la categoría general para las herramientas más pequeñas de Vyrron que son útiles en muchos tipos de servidores. Los comandos que crean imágenes, encuestas, temporizadores o recordatorios pueden publicar contenido visible o mantener estado, así que verifica el canal de destino y la duración antes de confirmar.

## Perfiles y multimedia

| Comando | Propósito |
| --- | --- |
| `/profile` | Ver una tarjeta de perfil |
| `/profileedit` | Crear o editar tu tarjeta de perfil |
| `/steal` | Copiar un emoji o sticker al servidor |
| `,quote` | Generar una imagen de cita |
| `/caption` | Añadir un pie de foto sobre una imagen |
| `/get pfp` | Obtener el avatar de un usuario |
| `/get banner` | Obtener el banner de un usuario |
| `/get wallpaper` | Obtener inspiración de fondos de pantalla |
| `/imdb` | Buscar una película o serie |
| `/embed` | Construir y enviar un embed personalizado |
| `/container` | Construir un contenedor de Components V2 |

## Temporizadores e interacción

| Comando | Propósito |
| --- | --- |
| `/poll create` | Crear una encuesta |
| `/poll end` | Finalizar una encuesta |
| `/timer start` | Iniciar un temporizador |
| `/timer pause` | Pausar un temporizador |
| `/timer resume` | Reanudar un temporizador |
| `/timer end` | Finalizar un temporizador |
| `/reminder add` | Añadir un recordatorio personal |
| `/reminder list` | Listar recordatorios activos |
| `/reminder remove` | Eliminar un recordatorio |
| `/timezone` | Ver o establecer una zona horaria |

<Note>
  Iniciar, pausar, reanudar y finalizar un temporizador son acciones de gestión del servidor en esta versión. Un temporizador usa el ID del mensaje devuelto por el flujo de inicio para su gestión posterior; mantén ese mensaje disponible si el staff necesita pausarlo o finalizarlo.
</Note>

## Otras herramientas

| Comando | Propósito |
| --- | --- |
| `/report` | Enviar un reporte de error |
| `/lookup` | Explorar nombres de usuario y vanities |
| `/define` | Buscar una definición |
| `/nptoggle` | Activar o desactivar el acceso sin prefijo personal |
| `/fix` | Descargar medios de Instagram o TikTok |
| `/lens` | Búsqueda inversa de imágenes |
| `/math` | Evaluar una expresión matemática |
| `/todo` | Gestionar tareas personales |

<Warning>
  `/report` envía un reporte de error al canal de desarrollo configurado, así que no incluyas contraseñas, tokens ni datos privados de miembros.
</Warning>
