Vyrron incluye una amplia colección de utilidades para administrar servidores, consultar información en línea, usar herramientas de inteligencia artificial y divertir a tu comunidad. Las funciones están organizadas en secciones temáticas para que encuentres rápidamente lo que necesitas.

Puedes explorar las subsecciones en detalle:

- [IA y media](/utility/ai)
- [Red y búsquedas web](/utility/network)
- [Roleplay y diversión](/utility/roleplay)
- [Varios](/utility/misc)

## Información del servidor y miembros

| Comando | Descripción |
| --- | --- |
| `/serverinfo` | Muestra información general del servidor |
| `/userinfo` | Muestra información de un miembro |
| `/roleinfo` | Muestra información de un rol |
| `/channelinfo` | Muestra información de un canal |
| `/emojiinfo` | Muestra información de un emoji |
| `/avatar` | Obtiene el avatar de un usuario |
| `/banner` | Obtiene el banner de un usuario |
| `/membercount` | Muestra el conteo de miembros del servidor |
| `/boosters` | Lista los miembros que impulsan el servidor |
| `/roles` | Lista los roles del servidor |
| `/emojis` | Lista los emojis del servidor |
| `/channels` | Lista los canales del servidor |
| `/permissions` | Muestra los permisos de un miembro en un canal |

<Note>
  `/setprofile` y `/prefix` también están disponibles como comandos de mensaje para ajustes rápidos sin usar barras.
</Note>

## IA y media

| Comando | Descripción |
| --- | --- |
| `/ai ask` | Haz preguntas a la inteligencia artificial |
| `/ai reason` | Solicita razonamiento paso a paso |
| `/ai ocr` | Extrae texto de una imagen |
| `/ai image` | Genera una imagen con IA |
| `/ai tts` | Convierte texto a voz sintetizada |
| `/recap` | Resume mensajes recientes de un canal |
| `/caption` | Añade un pie de foto a una imagen |
| `/steal` | Guarda un emoji o sticker en el servidor |
| `/get pfp` | Obtiene la foto de perfil de un usuario |
| `/get banner` | Obtiene el banner de un usuario |
| `/get wallpaper` | Obtiene un fondo de pantalla aleatorio |

<Note>
  El alias `,cap` funciona como atajo rápido para el comando `/caption`.
</Note>

## Búsquedas web y de red

Vyrron permite consultar información pública sobre direcciones IP, dominios, identidades y realizar búsquedas generales en la web.

| Categoría | Comando | Descripción |
| --- | --- | --- |
| IP | `/ip lookup` | Consulta información de una IP |
| IP | `/ip ports` | Escanea puertos comunes de una IP |
| IP | `/ip subnet` | Calcula información de subred |
| IP | `/ip geo` | Obtiene geolocalización de una IP |
| Dominios | `/domain whois` | Consulta registro WHOIS |
| Dominios | `/domain dns` | Consulta registros DNS |
| Dominios | `/domain screenshot` | Captura pantalla de un sitio web |
| Búsqueda | `/search web` | Busca en la web |
| Búsqueda | `/search image` | Busca imágenes en la web |
| Búsqueda | `/search news` | Busca noticias recientes |
| Identidad | `/username` | Busca un nombre de usuario en plataformas |
| Identidad | `/email` | Verifica información pública de un correo |

<Note>
  Usa estos comandos de forma responsable. La información recuperada es pública y Vyrron no garantiza su exactitud actual.
</Note>

## Herramientas personales

| Comando | Descripción |
| --- | --- |
| `/profile` | Muestra tu perfil personal en el servidor |
| `/profileedit` | Edita tu perfil personal |
| `/reminder add` | Crea un recordatorio |
| `/reminder list` | Lista tus recordatorios activos |
| `/reminder remove` | Elimina un recordatorio |
| `/timer start` | Inicia un temporizador |
| `/timer pause` | Pausa el temporizador activo |
| `/timer resume` | Reanuda el temporizador pausado |
| `/timer end` | Detiene el temporizador |

## Diversión comunitaria

Vyrron incluye más de 60 comandos de roleplay con GIFs animados para interactuar de forma casual con otros miembros. Desde abrazos y saludos hasta reacciones divertidas, puedes expresarte sin escribir una sola palabra. Usa `/help` para ver la lista completa de comandos de roleplay disponibles en tu servidor.
