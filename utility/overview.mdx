Estos comandos hacen que Vyrron sea útil más allá de la moderación y la configuración del servidor. Algunas herramientas son personales, algunas son de ámbito de servidor, y varias llaman a servicios externos públicos. Usa las páginas específicas para los detalles que importan antes de confiar en una búsqueda externa para una decisión de moderación. Para flujos de trabajo específicos, consulta [Herramientas de IA](/utility/ai), [Red y búsquedas web](/utility/network), [Roleplay](/utility/roleplay) y [Herramientas misceláneas](/utility/misc).

## Información del servidor y miembros

| Comando | Propósito |
| --- | --- |
| `/serverinfo` | Ver información del servidor |
| `/channelinfo` | Ver información del canal |
| `/userinfo` | Ver información de un miembro |
| `/roleinfo` | Ver información de un rol |
| `/vcinfo` | Ver información del canal de voz |
| `/avatar` | Mostrar un avatar |
| `/banner` | Mostrar el banner de un usuario |
| `/guildbanner` | Mostrar el banner del servidor |
| `/membercount` | Ver el conteo de miembros |
| `/boostcount` | Ver información de boosts |
| `/permissions` | Ver los permisos de un miembro |
| `/accountage` | Ver la antigüedad de la cuenta |
| `/lastseen` | Ver el último mensaje de un miembro |

`/setprofile` personaliza el perfil de servidor de Vyrron. `/prefix` es un comando de mensaje en esta versión: usa `,prefix` (o el prefijo actual del servidor) para ver y cambiar la configuración de prefijos.

## IA y multimedia

| Comando | Propósito |
| --- | --- |
| `/ai ask` | Hacerle una pregunta a la IA |
| `/ai reason` | Resolver un problema complejo |
| `/ai ocr` | Extraer y analizar texto de una imagen |
| `/ai tts` | Convertir texto a voz |
| `/recap` | Resumir mensajes recientes de un canal |
| `/rbg` | Eliminar el fondo de una imagen |
| `,quote` | Crear una imagen de cita a partir de un mensaje |
| `/caption` | Añadir un pie de foto sobre una imagen |
| `/fix` | Descargar medios de Instagram o TikTok |
| `/screenshot` | Capturar una página web |
| `/lens` | Búsqueda inversa de imágenes por imagen o URL |

`,cap` es un alias de comando de mensaje para `/caption`.

## Búsquedas web y de red

| Familia de comandos | Comandos disponibles |
| --- | --- |
| IP | `/ip lookup`, `/ip whois`, `/ip abuse`, `/ip asn`, `/ip ptr`, `/ip ports`, `/ip subnet`, `/ip ping` |
| Dominios | `/domain lookup`, `/domain dns`, `/domain ssl`, `/domain ip`, `/domain availability`, `/domain sub` |
| Búsqueda | `/search web`, `/search images`, `/search news`, `/pinterest` |
| Identidad | `/lookup`, `/sherlock` |

Usa estas herramientas de forma responsable y solo para información que estés autorizado a buscar. `/ip ports` realiza un escaneo de red de la lista de puertos comunes del comando, así que ejecútalo solo contra sistemas que poseas o tengas permiso explícito para probar. Los resultados de IP, DNS, WHOIS, búsqueda y servicios de búsqueda inversa de imágenes pueden estar incompletos o temporalmente no disponibles.

## Diversión comunitaria

Vyrron incluye 60 comandos de roleplay como `/hug`, `/kiss`, `/pat`, `/wave`, `/dance`, `/celebrate`, `/cry`, `/laugh`, `/punch`, `/slap`, `/thumbsup`, `/wink`, `/yay` y `/yawn`. Usa `/help` en Discord para abrir el menú de ayuda y explorar el conjunto completo. Para ver los detalles de un comando específico, usa `,help cmdname`. El inventario completo también está listado en la [referencia de comandos](/reference/commands).

## Información del bot

```text
/about
/stats
/uptime
/ping
/users
/vote
/support
/invite
/help
```

Usa `,help cmdname` cuando necesites las opciones de un comando específico. El prefijo puede ser diferente si tu servidor lo ha cambiado.
