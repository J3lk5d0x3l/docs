Vyrron permite recuperar información pública sobre direcciones IP, dominios, búsquedas web e identidades en línea. Estos comandos consultan fuentes públicas y no establecen propiedad sobre los datos ni garantizan su seguridad o exactitud actual.

## Comandos de IP

| Comando | Descripción |
| --- | --- |
| `/ip lookup` | Consulta información general de una dirección IP |
| `/ip geo` | Obtiene datos de geolocalización de una IP |
| `/ip ports` | Escanea puertos comunes de una dirección IP |
| `/ip subnet` | Calcula información de subred a partir de una IP |
| `/ip reverse` | Realiza una búsqueda inversa de DNS |
| `/ip abuse` | Consulta reportes de abuso asociados a una IP |
| `/ip reputation` | Muestra la reputación general de una IP |
| `/ip history` | Consulta el historial conocido de una IP |

<Note>
  `/ip ports` realiza un escaneo básico de puertos comunes. `/ip subnet` calcula el rango de red, la máscara y otros datos útiles para diagnóstico de red.
</Note>

## Comandos de dominio

| Comando | Descripción |
| --- | --- |
| `/domain whois` | Consulta el registro WHOIS de un dominio |
| `/domain dns` | Consulta los registros DNS de un dominio |
| `/domain screenshot` | Captura una imagen de la página principal del dominio |
| `/domain subdomains` | Lista subdominios conocidos de un dominio |
| `/domain history` | Muestra el historial de cambios conocidos del dominio |
| `/domain reputation` | Consulta la reputación general del dominio |

## Comandos de búsqueda e identidad

| Comando | Descripción |
| --- | --- |
| `/search web` | Realiza una búsqueda general en la web |
| `/search image` | Busca imágenes relacionadas con una consulta |
| `/search news` | Busca noticias recientes sobre un tema |
| `/username` | Busca un nombre de usuario en múltiples plataformas |
| `/email` | Verifica información pública asociada a un correo electrónico |
| `/phone` | Consulta información pública de un número telefónico |
| `/social` | Busca perfiles públicos en redes sociales |

<Warning>
  Usa estos comandos únicamente en sistemas y redes autorizados. Los resultados provienen de fuentes públicas y pueden estar incompletos, desactualizados o almacenados en caché. Vyrron no garantiza la exactitud ni la vigencia de la información recuperada.
</Warning>
