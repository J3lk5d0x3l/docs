Vyrron reproduce música de alta calidad en Discord a través de Lavalink. Puedes reproducir desde YouTube Music, Spotify, SoundCloud, Apple Music, Audiomack y Tidal, además de gestionar colas, letras y canciones favoritas directamente desde el chat.

## Fuentes de música

Vyrron soporta las siguientes fuentes de audio:

| Fuente | Tipo |
| --- | --- |
| YouTube Music | Búsqueda, reproducción directa |
| Spotify | Búsqueda, reproducción directa |
| SoundCloud | Búsqueda, reproducción directa |
| Apple Music | Búsqueda, reproducción directa |
| Audiomack | Búsqueda, reproducción directa |
| Tidal | Búsqueda, reproducción directa |

## Inicia una sesión

Usa los siguientes comandos para comenzar a reproducir música en tu canal de voz:

```text
/play <consulta>
/search <consulta>
/spotify <consulta>
/lyrics <canción>
```

<Note>
  `/search` te permite elegir entre varios resultados antes de reproducir. `/play query` reproduce el primer resultado directamente. `/spotify` busca y reproduce desde Spotify.
</Note>

## Controles de reproducción

| Comando | Descripción |
| --- | --- |
| `/play` | Reproduce una canción o añade a la cola |
| `/pause` | Pausa la reproducción actual |
| `/resume` | Reanuda la reproducción pausada |
| `/stop` | Detiene la reproducción y limpia la cola |
| `/skip` | Salta la canción actual |
| `/previous` | Vuelve a la canción anterior |
| `/seek` | Adelanta o retrocede en la canción actual |
| `/volume` | Ajusta el volumen del reproductor |
| `/nowplaying` | Muestra la canción en reproducción |
| `/loop` | Activa o desactiva el bucle de canción o cola |
| `/shuffle` | Mezcla las canciones de la cola |
| `/disconnect` | Desconecta al bot del canal de voz |
| `/247` | Mantiene al bot conectado 24/7 en el canal |

## Herramientas de cola y sesión

| Comando | Descripción |
| --- | --- |
| `/queue` | Muestra la cola de reproducción actual |
| `/clearqueue` | Elimina todas las canciones de la cola |
| `/remove` | Elimina una canción específica de la cola |
| `/move` | Mueve una canción a otra posición en la cola |
| `/swap` | Intercambia dos canciones de la cola |
| `/skipto` | Salta a una posición específica de la cola |
| `/replay` | Vuelve a reproducir la canción actual |
| `/grab` | Guarda la canción actual en tus favoritos |
| `/lyrics` | Muestra la letra de la canción actual o buscada |
| `/autoplay` | Activa la reproducción automática de recomendaciones |
| `/filter` | Aplica filtros de audio (bassboost, nightcore, etc.) |
| `/speed` | Cambia la velocidad de reproducción |

## Canciones favoritas

Guarda y gestiona tus canciones favoritas para reproducirlas más tarde:

```text
/favorites add
/favorites remove
/favorites list
/favorites play
/favorites clear
```

El comando `/grab` guarda la canción que se está reproduciendo directamente en tu lista de favoritos. Puedes reproducir toda tu lista con `/favorites play` y gestionar los elementos con `add`, `remove`, `list` y `clear`.

## Resolución de problemas de música

1. Verifica que Vyrron tenga permisos para unirse al canal de voz y hablar.
2. Asegúrate de que la consulta de búsqueda esté escrita correctamente.
3. Comprueba que la fuente de música (YouTube, Spotify, etc.) esté disponible.
4. Si no hay sonido, revisa el volumen del bot con `/volume`.
5. Si el bot no responde, expúlsalo y vuelve a invitarlo al canal con `/disconnect` seguido de `/play`.
