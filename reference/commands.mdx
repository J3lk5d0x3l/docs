Usa esta página para encontrar el comando adecuado para tu servidor. Los comandos están agrupados por función para que puedas ir directamente a la configuración, protección, sistemas de comunidad, música o utilidades cotidianas. Usa comandos de barra donde estén disponibles. Los comandos de mensaje usan el prefijo configurado del servidor, como `,prefix` o `!prefix`.

Algunos comandos requieren permisos de servidor. Los comandos que usan servicios externos también pueden verse afectados por la disponibilidad del proveedor o límites de tasa.

## Cómo obtener ayuda de comandos en Discord

Usa `/help` para abrir el menú de ayuda y explorar las categorías disponibles. Los comandos de barra solo están disponibles para los comandos registrados con Discord; los comandos exclusivos de mensaje usan el prefijo configurado. Para obtener detalles de un comando, usa:

```text
,help cmdname
```

Discord mostrará las opciones y subcomandos disponibles para la versión instalada del comando. Si un comando no aparece, verifica que los comandos de aplicación de Vyrron estén disponibles en el servidor y que estés usando el nombre correcto del comando. Algunos comandos permanecen intencionalmente solo como comandos de mensaje, incluyendo la gestión de prefijos en esta versión.
