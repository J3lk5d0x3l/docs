Automod maneja la protección a nivel de mensajes: spam, enlaces no deseados, palabras prohibidas, contenido NSFW, abuso de mayúsculas, menciones masivas, spam de emojis y adjuntos, mensajes largos, spam de saltos de línea y contenido repetido entre canales. Configúralo gradualmente y combínalo con logging para que el staff pueda revisar falsos positivos.

## Comandos

| Comando | Para qué usarlo |
| --- | --- |
| `/automod setup` | Configurar módulos de automod |
| `/automod enable` | Activar automod |
| `/automod disable` | Pausar automod |
| `/automod reset` | Eliminar configuración de automod |
| `/automod whitelist` | Gestionar excepciones de automod |

## Módulos disponibles

El panel de configuración expone actualmente estos módulos:

| Módulo | Qué detecta |
| --- | --- |
| Anti Spam | Ráfagas y contenido repetido |
| Anti Link | Enlaces externos, acortadores y URLs de IP |
| Anti Invite | Enlaces de invitación de Discord |
| Anti Bad Words | Lista multilingüe integrada o lista personalizada |
| Anti NSFW | Texto e imágenes NSFW |
| Anti Caps | Mayúsculas excesivas y abuso de caracteres combinados |
| Anti Ping | Pings a `@everyone` y `@here` |
| Anti Mass Mention | Ráfagas de menciones grandes o repetidas |
| Anti Emoji Spam | Mensajes con exceso de emojis |
| Anti Attachment Spam | Múltiples archivos o ráfagas rápidas de subida |
| Anti Char Limit | Mensajes de más de 900 caracteres |
| Anti Newline Spam | Mensajes con 8 o más saltos de línea |
| Anti Scam Spread | El mismo mensaje publicado en 3 o más canales |

Los módulos de palabras prohibidas y NSFW también sincronizan reglas de Discord AutoMod cuando el bot tiene **Gestionar Servidor**. La lista de palabras prohibidas integrada es multilingüe; usa la opción de lista personalizada del panel cuando el servidor necesite su propio vocabulario.

## Implementación recomendada

<Steps>
  <Step title="Empieza en un canal de prueba">
    Usa un canal privado del staff o un servidor de prueba pequeño para validar el comportamiento.
  </Step>
  <Step title="Activa una capa a la vez">
    Registra qué filtros están activos y qué deben hacer cuando coincidan.
  </Step>
  <Step title="Revisa las excepciones">
    Añade solo los canales, usuarios o roles que genuinamente necesiten una excepción.
  </Step>
  <Step title="Monitorea los logs">
    Observa el canal de logging para detectar falsos positivos después de activar automod.
  </Step>
</Steps>

<Tip>
  Si un filtro es demasiado agresivo, pausa automod con `/automod disable`, ajusta la configuración y vuelve a probar en lugar de añadir entradas amplias a la lista blanca.
</Tip>
