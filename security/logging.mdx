El registro de eventos (logging) proporciona al staff un registro dedicado de eventos que son difíciles de reconstruir más tarde. Vyrron almacena cinco destinos de registro: mensajes, miembros, moderación, voz y eventos del servidor. Usa canales privados o la categoría privada automática `Vyrron Logs`.

## Comandos

| Comando | Úsalo para |
| --- | --- |
| `/logging setup` | Elegir y configurar los canales de registro |
| `/logging enable` | Habilitar el registro de eventos |
| `/logging disable` | Pausar el registro de eventos |
| `/logging reset` | Eliminar la configuración de registro |

## Qué recibe cada canal

| Destino | Ejemplos |
| --- | --- |
| Registro de mensajes | Ediciones, eliminaciones y eliminaciones masivas de mensajes |
| Registro de miembros | Entradas, salidas, kicks, cambios de roles y cambios de apodo |
| Registro de moderación | Bans, desbaneos y timeouts |
| Registro de voz | Entradas, salidas, movimientos y cambios de estado en canales de voz |
| Registro de servidor | Cambios en canales, roles, emojis, stickers y configuración del servidor |

## Lista de verificación de configuración

- Crea canales de registro exclusivos para el staff, o deja que Vyrron cree la categoría `Vyrron Logs` automáticamente.
- Otorga a Vyrron permiso para ver y enviar mensajes allí. La configuración automática también necesita **Gestionar canales**; la entrega mediante webhooks necesita **Gestionar webhooks**.
- Ejecuta `/logging setup`.
- Activa un evento de prueba inofensivo.
- Confirma que el evento aparece antes de habilitar el antinuke o el automod.

El registro solo es útil cuando el staff puede acceder a él. Mantén los canales privados, pero asegúrate de que el equipo de moderación de guardia pueda leerlos durante un incidente.
