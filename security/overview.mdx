Vyrron tiene tres capas de protección del servidor:

1. **Antinuke** monitorea acciones destructivas del servidor y miembros, y proporciona listas de confianza de usuarios, roles y propietarios adicionales.
2. **Automod** filtra mensajes arriesgados o no deseados con 13 módulos seleccionables.
3. **Logging** registra eventos de mensajes, miembros, moderación, voz y servidor para revisión del staff.

Lee las guías detalladas de [Antinuke](/security/antinuke), [Automod](/security/automod) y [Registro](/security/logging) cuando estés listo para configurar cada capa.

## Orden recomendado

<Steps>
  <Step title="Configura el registro">
    Ejecuta `/logging setup`, elige los canales de log y luego `/logging enable`. El registro da al staff el contexto necesario para ajustar las otras capas.
  </Step>
  <Step title="Configura automod">
    Ejecuta `/automod setup`, revisa los módulos y luego `/automod enable`. Usa `/automod whitelist` para excepciones cuidadosamente revisadas.
  </Step>
  <Step title="Activa antinuke">
    Ejecuta `/antinuke enable`, inspecciona `/antinuke status` y gestiona excepciones de confianza con `/whitelist` y `/extraowner`.
  </Step>
</Steps>

## Comandos de Antinuke

| Comando | Propósito |
| --- | --- |
| `/antinuke enable` | Activar protección antinuke |
| `/antinuke disable` | Pausar protección |
| `/antinuke config` | Ver configuración de antinuke |
| `/antinuke status` | Ver el panel de seguridad y módulos activos |
| `/antinuke reset` | Borrar configuración de antinuke |
| `/whitelist add` | Permitir un usuario o rol |
| `/whitelist remove` | Eliminar una entrada de la lista blanca |
| `/whitelist` | Gestionar entradas de la lista blanca interactivamente |
| `/extraowner add` | Añadir un propietario adicional |
| `/extraowner remove` | Eliminar un propietario adicional |
| `/extraowner manage` | Gestionar propietarios adicionales interactivamente |
| `/extraowner reset` | Eliminar todos los propietarios adicionales |

<Note>
  Una lista blanca es un límite de confianza, no una lista de conveniencia. Mantenla pequeña, revísala regularmente y nunca añadas un rol solo porque es fácil de seleccionar.
</Note>

## Reglas prácticas de operación

- Mantén los logs en canales solo para staff. El registro automático crea cinco canales bajo una categoría privada `Vyrron Logs` cuando tiene los permisos requeridos.
- Prueba los filtros con una cuenta de moderador antes de activarlos en todo el servidor.
- Combina acciones automáticas con logs para que el staff pueda auditar falsos positivos.
- Pausa una capa antes de cambiarla si el servidor está activamente ocupado.
- Si estás respondiendo a un incidente, usa `/antinuke status` antes de cambiar la configuración.
