Vyrron solo puede hacer lo que Discord permite en el canal actual, y la jerarquía de roles de Discord siempre prevalece.

## Permisos mínimos útiles

Para el conjunto completo de funciones, Vyrron generalmente necesita:

- Ver Canales
- Enviar Mensajes
- Enviar Mensajes en Hilos
- Insertar Enlaces
- Adjuntar Archivos
- Leer Historial de Mensajes
- Añadir Reacciones
- Gestionar Mensajes
- Gestionar Canales
- Gestionar Roles
- Expulsar Miembros
- Banear Miembros
- Moderar Miembros
- Conectar y Hablar

El enlace de invitación de este proyecto solicita un amplio conjunto de permisos de bot porque Vyrron incluye moderación, gestión de canales, paneles de roles, tickets, logging y reproducción de voz. Si usas una invitación personalizada, concede permisos solo para las funciones que realmente actives. Algunos sistemas necesitan permisos adicionales, y puedes ejecutar `/permissions` para inspeccionar los permisos de un miembro en contexto.

## Jerarquía de roles

Mueve el rol de Vyrron **por encima** de:

- Los roles que debe asignar mediante autorole, selfrole o comandos de moderación.
- Los miembros que debe moderar.
- Los canales que debe gestionar.

Vyrron no puede gestionar un rol que sea igual o superior a su propio rol más alto, incluso si el bot tiene el permiso `Gestionar Roles`.

## ¿Quién debe configurar qué?

| Área | Acceso recomendado |
| --- | --- |
| Prefijo, perfil, recordatorios, música | Miembros, según la política de tu servidor |
| Bienvenida, niveles, sugerencias, feedback | Administradores o staff de confianza |
| Tickets y roles de soporte | Administradores y líderes de soporte |
| Moderación y gestión de canales | Moderadores con los permisos de Discord correspondientes |
| Automod, logging, antinuke, propietarios adicionales | Propietarios del servidor y administradores senior |

<Warning>
  Trata `/antinuke reset`, `/automod reset`, `/logging reset` y `/leveling reset` como acciones de configuración destructivas. Revisa la confirmación que muestra Discord antes de enviarlas.
</Warning>

## Solución de problemas de acciones denegadas

1. Comprueba el permiso de Discord requerido por el comando.
2. Comprueba el permiso del canal para Vyrron.
3. Comprueba si el rol de Vyrron está por encima del miembro o rol objetivo.
4. Comprueba si el canal está ignorado con `/ignore`.
5. Reintenta con el comando slash para que Discord pueda mostrar las opciones disponibles.

Si Vyrron no puede enviar una respuesta en absoluto, concede **Ver Canal** y **Enviar Mensajes** en ese canal primero. Para la configuración de logging, también concede **Gestionar Canales** si usas la creación automática de canales y **Gestionar Webhooks** si Vyrron debe crear sus webhooks de logging. Para tickets, necesita crear y gestionar canales de texto privados y permisos de sobreescritura.
